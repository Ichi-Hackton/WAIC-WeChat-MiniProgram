單文件入口 + 按功能劃分的 handler 模組，無第三方框架。
- `src/server.ts`：使用 `node:http` 創建服務、解析 JSON body（1MB 上限）、健康檢查（`GET /`、`/healthz`），並從三個 handler 模組匯出的 `entries` 陣列合併路由表（Map key 為 `METHOD /path`）。
- `src/api.ts`：定義跨模組共享的協議類型（`CloudResponse`、`RequestContext`、`RouteHandler`、`HandlerResult`）及統一回應建構器（`ok`/`fail`/`badRequest`/`unauthorized`/`forbidden`），是 server 與各 handler 之間的唯一契約層。
- `src/llm-chat.ts`、`src/skill-train.ts`、`src/skill-coffee.ts`：各自匯出 `xxxRoutes: Array<[string, RouteHandler]>`，由 server 以展開語法合併；handler 內部僅依賴 `./api`，不互相引用。
- 部署側：`Dockerfile` 基於 `node:20-alpine`，編譯 TypeScript 後以 `dist/server.js` 啟動，監聽 `PORT` 環境變數（預設 80），符合微信雲托管規範。
- 依賴方向嚴格單向：server → handlers → api；外部 LLM 呼叫透過 Node 18+ 內建 `fetch` 完成，無額外加載依賴。
