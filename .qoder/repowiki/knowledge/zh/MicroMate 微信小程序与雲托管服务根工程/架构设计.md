根目录作为双端工程的装配层：`project.config.json` 将 `miniprogram/` 注册为小程序项目根并启用 TypeScript 编译器插件；`tsconfig.json` 仅对 `miniprogram/**/*.ts` 执行 `noEmit` 类型检查，并通过 `@/*` path alias 指向 `miniprogram/src/*`，使小程序侧代码获得统一的 TS 校验；`cloudrun/` 子模块是独立的零依赖 Node.js HTTP 服务（LLM 代理与 SKILL 端点），由微信雲托管运行，与小程序通过 HTTP 调用通信，二者之间无共享源码或运行时依赖，仅以 API 契约对接。
