- 每个子模块通过 `index.ts` 统一 re-export 子文件，对外只暴露聚合入口（如 `src/core/index.ts`、`src/services/index.ts`、`src/skills/index.ts`）。
- 跨层共享的类型集中在 `src/types/` 下以 `.d.ts` 或独立 TS 文件声明，并由各层 `index.ts` 重新导出，避免循环依赖。
- 核心编排逻辑（Orchestrator）通过回调注入 UI 行为（`confirmPlan`、`checkpoint`、`onStateChange` 等），保持 core 不反向依赖 interaction。
- 全局可变的单例（`SkillRegistry`、`runtimeSingleton`）采用惰性初始化 + 幂等返回，并在注释中明确说明重复调用的语义。
- 对外错误响应统一携带 `state`、`errorCode`（如 BUSY、EMPTY_PLAN、DEADLOCK、UNEXPECTED、RUN_RESET）与人类可读 message，便于 UI 分支处理。
- 日志输出通过 `utils/logger` 的 `info/warn/error` 函数，关键路径（handleIntent、Orchestrator.handle、reset）均记录意图前缀与状态变化。
