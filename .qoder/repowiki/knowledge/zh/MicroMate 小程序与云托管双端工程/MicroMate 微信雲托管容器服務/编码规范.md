- 每個 handler 模組匯出一個 `xxxRoutes` 陣列，元素為 `[methodPath, handlerFn]` 元組，供 server 以展開語法合併到全局路由表。
- handler 函數簽名統一為 `(body: unknown, ctx: RequestContext) => Promise<HandlerResult>`，返回 `{ httpStatus, body: CloudResponse }` 結構。
- 業務回應一律透過 `api.ts` 導出的 `ok`/`fail`/`badRequest`/`unauthorized`/`forbidden` 建構器生成，禁止手寫 `CloudResponse` 字面量。
- 外部配置（LLM base URL、API Key、模型名）全部從 `process.env` 讀取，不在代碼中硬編碼。
- 錯誤語義與小程序端對齊：業務失敗回傳 HTTP 200 + `code ≠ 0`，網路/上游錯誤回傳 4xx/5xx（如 503 標記為可重試）。
